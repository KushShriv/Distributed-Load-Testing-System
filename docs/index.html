To run a test, download or clone the project, review it, and run ./start.sh. A packaged release is not yet published.

Local mode

Start ./start.sh, then enter the pairing code shown in your terminal. The code stays in this page’s memory and is cleared when you close or reload it.

Not connected.

If the browser blocks the connection or local network permission, open the local dashboard instead. No connection is attempted until you click Connect.

Test settings

Each worker sends one request at a time. Up to 100 workers and 10,000 total requests. The test sends real traffic to the target and any redirects.
